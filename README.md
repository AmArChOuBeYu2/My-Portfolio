## ✨ Key Features & Architecture

### 1. 🌿 Main Portfolio (`index.html`)
- **Psychological Color Harmony**: Built with Botanical Sage Green (`#5B7C61`) for focus & serenity, Warm Terracotta Amber (`#C86A4B`) for attraction, and Soft Alabaster/Obsidian Charcoal (`#F7F6F2` / `#1B1C1E`). Zero generic AI neon clutter!
- **Interactive 3D Canvas Background**: Three.js WebGL scene with soft-lit floating geometric monuments that react to cursor movement and section scrolling.
- **Telemetry HUD**: Real-time flight telemetry displaying scroll metric, 3D FPS meter, active section stage, and audio toggle.

### 2. ☀️ NASA 3D Solar System Expedition (`solar.html`)
- **Celestial Orbits & Procedural Shaders**:
  - **Sun**: Multi-layer solar corona flare, glowing yellow/orange surface, and central lighting point source.
  - **Earth & Moon**: Deep blue ocean map, green continents, swirling white cloud atmosphere layer, orbiting Moon, and an artificial satellite with a blinking green beacon light.
  - **Jupiter**: Procedural gas storm bands featuring the **Great Red Spot storm**.
  - **Mars**: Red iron oxide terrain with white polar ice caps.
  - **Saturn**: Magnificent multi-ring disk with Cassini division transparency.
- **Real-Time Selection Glow Aura**: Selecting any celestial body attaches a **pulsing cyan selection aura sphere** and an **orbiting wireframe ring** that tracks the planet along its orbit in real-time.
- **Deep Space Environment & Easter Eggs**:
  - **6,500+ Twinkling Starfield** & cosmic nebula dust cloud.
  - **Black Hole Easter Egg**: Gravitational lensing visual effect located in deep space coordinates (`x: -350, y: 180, z: -450`).
  - **Passing Comets**: Animated icy comets with glowing particle tails sweeping periodically.
  - **Asteroid Belt**: 480+ irregular asteroids orbiting between Mars and Jupiter.
- **WASD Flight Game Controls**:
  - `W` / `A` / `S` / `D` or `Arrow Keys`: Fly through space in Free-Flight Mode (`Space` = Thrust Up, `Shift` = Thrust Down).
  - `Mouse Drag`: Camera pitch and yaw look direction.
- **Interstellar Theme Acoustic Synth**: Ambient pipe organ & synth arpeggio soundscape inspired by Hans Zimmer's *Interstellar* (*A minor / F major / C major / G major*).

## 🛠️ Local Development & Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/AmArChOuBeYu2/My-Portfolio.git
   cd My-Portfolio
   ```

2. **Serve locally**:
   You can serve the static files using Python or Node.js:
   ```bash
   python -m http.server 3000
   # or
   npx serve .
   ```

3. **Open in browser**:
   Navigate to `http://localhost:3000` or open `index.html` directly!
